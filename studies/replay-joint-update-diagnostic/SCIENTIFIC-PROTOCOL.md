# Same-state JOINT replay intervention, v1

Public scientific-method projection of the original pre-outcome design. This document retains the scientific design and failure criteria, omits procedural status text, and is not the original frozen document. The study remains post-hoc because the historical states, dataset and earlier study outcomes were already known. Full-precision outcomes are reported separately.

## Question, scope, and epistemic status

The deployed NumPy 196→32→10 float32 SGD learner commits ONE step on the mean cross-entropy of 16 fresh + 10 replay examples at eta=0.3. Its earlier mechanism audit instead started at the virtual fresh-only update and then committed replay-only SGD. These interventions differ in weighting, parameter location, and step count. A sequential result cannot be relabeled as a JOINT result.

Test whether MIR-selected items improve independently measured old-panel loss compared with high-current-loss and within-class uniform items when all branches start from identical parameter bytes, candidate IDs, fresh batch, class quotas, and eta and actually use the deployed JOINT step. Historical Fashion data, seeds, checkpoints and outcomes have been seen. This is a POST-HOC DIAGNOSTIC, not a prospective independent confirmation, new test set, new biological evidence, or evidence that a local effect improves future retention. Freezing this audit before its new outcomes prevents within-audit tuning but cannot restore prior independence.

## Frozen state selection, no favorable-state filtering

Use historical evaluation seeds [2001,2002,2003,2004], origin arm `uniform`, locked eta=0.3. For each seed use the four historical end-of-block checkpoints block-[0,1,2,3].npz. Sixteen states, FOUR seed/stream clusters, not sixteen independent trials. The first 4 seeds in the historical predeclared order and all boundaries with a next batch are chosen mechanically, not by accuracy, score, class identity or observed effect. Uniform origins avoid selecting states generated by either compared score selector; inference is conditional on this uniform-trajectory state distribution, not all states or MIR trajectories.

For block b reconstruct the reservoir by replaying only historical admissions over saved stream positions [0:2000*(b+1)], in batches of 16, with the unmodified deployed Reservoir and seed. Do NOT retrain or update the checkpoint. Verify saved stream indices equal the source-defined seeded stream, class-pair JSON agrees, parameter shapes/dtypes/finiteness pass, and checkpoint hash matches the retained case inventory. Fresh batch is exactly the next 16 stream positions, repetition 0, before admission. Global zero-based committed-update offset is u=500*(b+1). This is a genuine pre-update state at a block transition, but does not represent mid-block states.

Generate up to 50 class-balanced candidate IDs with the deployed candidate routine, same u and reconstructed memory, using a newly frozen state-specific audit RNG domain independent of outcomes and selectors. These candidate draws need not equal the original next deployment draw; the candidate-allocation law does. Allocate exactly ten replay slots with deployed quotas. Every branch uses the SAME candidates and label quota and no candidate/fresh ID overlap. No replacement, no evaluator examples in replay. Log full reservoir IDs, candidate IDs/labels, fresh IDs/labels, quota, hashes and score arrays.

## Selectors, ties and controls

Compute signed MIR delta_i = loss_i(theta - eta*grad mean fresh) - loss_i(theta), and current loss_i at the shared original theta. Nonfinite values fail the state; never clip negative/zero scores and never substitute a favorable fallback.

Primary: MIR and high-loss with the deployed exact-equality tie rule, increasing numeric source ID within class. Uniform control is the equal-weight mean of FOUR independently seeded within-class without-replacement draws 0..3. This repeated-draw mean reduces selection noise; draws are not independent scientific samples. Uniform is not padded by score permutations and no redundant shuffled-score arm is claimed independent.

Sensitivity: MIR and high-loss with independent randomized priorities used ONLY among exactly tied scores. One state-specific canonical-ID priority permutation, shared across the two score selectors, is drawn independently of scores and candidate draws. This keeps ranking of strictly unequal scores unchanged. Near-equality abs(score-cutoff)<=1e-7 is separately LOGGED, never used to turn unequal scores into ties. Each selector/class records cutoff, exact equal/above counts, exact tied selected/rejected IDs, cutoff-straddling flag, near-boundary IDs/counts and actual chosen IDs. Explicitly report how often random ties alter IDs and local outcomes. No inference about historical cutoff ties is reconstructed from old summary counts.

For every chosen replay set, compute (a) ONE JOINT step from theta on concatenated 16+10, and (b) the older SEQUENTIAL diagnostic theta_f=step(theta,fresh), then step(theta_f,replay). Both are independently cloned, discarded audit branches. Also retain unmodified theta and fresh-only theta_f baselines. JOINT is primary; sequential is a diagnostic factor, not an additional success opportunity or substitute. Every branch has identical fresh IDs and quota. No training continuation, persistent optimizer changes or audit feedback.

## Evaluation data and endpoints

Use ALL 500 historical validation examples per old class, from prepared-v1 val_ids, independent of reservoir/candidate/fresh membership and exact raw/transformed feature groups. Old labels are the union of completed class pairs including b. Primary old endpoint is class-macro mean cross-entropy in NATURAL LOG units, equal weight per old class. Validate that the panel has exactly 500/class; abort instead of selecting an easier panel. New-class plasticity endpoint uses the 500/class validation items for the next pair. The official test images/labels are NOT opened or scored. Historical validation was used for rate selection; independence from the learner state is not independence from study design. No claim of unseen data, subjects or domain generality.

For state s, D_H(s)=oldloss(JOINT MIR)-oldloss(JOINT highloss), D_U(s)=oldloss(JOINT MIR)-mean_draw oldloss(JOINT uniform). Negative favors MIR. Log each branch's signed old/new loss change relative to theta, and relative to fresh-only, without clipping. Primary D_H uses source-ID ties. Uniform D_U and randomized ties are secondary descriptive contrasts. Compute sequential D_H and the within-state interaction D_H_joint-D_H_seq using the SAME selections and panels, not the historical adverse result. Report per-state values, within-seed means, equal-weight seed mean, and a descriptive percentile seed-cluster bootstrap (10,000 resamples, seed7310301). Never pool state/example/draw rows as independent samples; 4 clusters are inadequate for strong tail confidence or power claims. All intervals describe these fixed data and historical stream seeds only.

## Falsifiability, practical resolution and failure criteria

Fix a diagnostic practical resolution epsilon=0.005 nats/example per one update BEFORE new outcomes. This is an engineering interpretive yardstick, not a powered minimally detectable effect or established retention benefit. Show raw values and sensitivity yardsticks 0.001 and 0.010 without picking whichever looks favorable. A mean D_H>=0 contradicts the local protection prediction at these states; a bootstrap interval fully inside [-epsilon,+epsilon] supports only practical-smallness for this diagnostic; an interval crossing -epsilon leaves a practically meaningful advantage unresolved. A mean below -epsilon with upper interval below -epsilon is a candidate local-mechanism signal ONLY, requiring independent design/replication before any general claim. Uniform superiority, new-panel loss worsening and tie sensitivity must be foregrounded even if high-loss looks favorable. No binary confirmatory-success label is permitted.

A useful improvement jump means resolving the ACTUAL causal ambiguity: changing only update composition reverses or preserves the signed local contrast with useful precision, or measured cutoff ties explain selection/outcome differences. More tests, prose, bootstrap draws, or a larger favorable mean alone do not qualify. If the 4-seed interval spans both -epsilon and +epsilon, the next design targets precision using independent new-stream seeds under separately reviewed caps, not post-hoc selector/rate changes. If JOINT is adverse or practically small, keep that result and investigate score-to-protection mismatch rather than scale the model. If JOINT differs materially from SEQUENTIAL, next isolate weighting versus parameter-location with predeclared weighted-joint and split-step controls. If randomized ties materially change D_H (>epsilon or sign), prioritize tie replication; otherwise don't market generic tie counts as causal explanation. A positive local result does NOT complete the retention chain: next separately freeze a short-horizon continuation from the same state with fixed intervening data and independent retention panels. Recurrent/gradual streams and biological bridge work remain later experiments.

Software/state failures abort the ENTIRE small diagnostic bundle, preserving partial signed outputs and failure record; never omit a seed/state, favorable restart, silently change split/eta/state list, or classify resource exhaustion as evidence. Fail on source/input hash mismatch, historical checkpoint mismatch, state shape/dtype/nonfinite, wrong stream/class pairs, insufficient panel counts, duplicates/cross-split feature overlap, quotas <10 or unequal, branch mutation, missing candidate/cutoff/panel provenance, output collision, or caps exceeded. A reproducible bug requires a dated protocol/source amendment and complete affected-bundle rerun, not favorable surviving rows.

## Recorded resource boundary

The original source specified four seed clusters, four states per seed, eight replay selections per state and two update compositions, plus a shared fresh-only baseline: 272 planned SGD calls, 32 planned candidate forward passes and 1,008,000 planned panel-example forward evaluations. These are source-graph counts, not instrumented runtime counters. No persistent learner continuation was performed.

Resource controls used per-process CPU soft/hard limits 180/181 seconds, address-space limit 768 MiB, per-file size limit 32 MiB, a wall signal at 300 seconds and an outer termination backstop. Observed RSS and aggregate output gates were sampled, not guaranteed hard RSS, total-output or exact-wall bounds. Core dumps were disabled. Pre-completion samples were CPU 1.507592503 seconds, wall 1.5238900690019364 seconds and RSS high-water 94,314,496 bytes; these are not final process-end timings. The original saved completion-inclusive byte total is 1,060,107. Public packaging bytes are not experimental resource usage. See resource-ledger.json.

No official TEST images or labels were used in this diagnostic. The distributed recount does not read any image, label, feature, model or checkpoint array. No scientific rerun was performed for this release.
