# Synthetic projection control: corrected successor

This is a post-hoc synthetic mathematical control, not a preregistered experiment or a frozen protocol. It corrects an earlier local scratch control that hard-coded its projected vectors, exited on the first failure, and described three equalities while listing four assertions. That scratch predecessor is not included in this package.

Run `python control.py` and `python -m unittest -v` from this directory. The control evaluates all four original assertions with absolute tolerance 1e-12, prints every result and the actual passed/total denominator, and exits nonzero if any fail. Projected updates are calculated from the supplied gradients using twice-reorthogonalized modified Gram–Schmidt. Numerical dependence is determined relative to each input gradient's norm at a fixed 1e-12 threshold, so nearly dependent spans are numerical approximations, not an exact-rank guarantee. Because rows are processed sequentially, the chosen numerical span and projected result can depend on row order near the threshold. This is not an SVD-based rank decision. This illustrative implementation is not designed for extreme magnitudes or a high-dimensional training workload.

These are synthetic mathematical controls, not a replay-performance estimate. First-order orthogonality neither guarantees old-loss nonincrease nor protection of held-out old gradients. The held replay study remains separate and on hold. This control does not imply that datasets, training, tuning, checkpoint inference, or held-out performance results were produced for the held replay study. Any genuine application would need a separately specified prospective paired-seed study and reporting safeguards; this illustrative control is not that study.
