# Data, model and dependency provenance

## Original materials

- Original implementation: all files under `src/`, `tests/`, and `scripts/` were written for this project. No external repository implementation was copied. License: MIT, in the root `LICENSE`.
- Synthetic data: generated by `src/functional_circuits/data.py` from explicitly recorded NumPy seeds. There are no external datasets, human subjects, personal records, or scraped examples. The generator and generated outputs are MIT licensed.
- Category definitions: two fixed six-dimensional nonlinear score functions; random balanced categories; episode-local memory banks of four entries; exact key lookup. See the generator, `docs/design.md`, and run manifest for full rules and seeds.
- Trained model weights: generated from scratch by this project's implementation and synthetic data. No pretrained models, external weights, or model downloads. Checkpoints are MIT licensed; NumPy archives contain numeric arrays only and load with `allow_pickle=False`.
- Results and documentation: original analysis and measurements, MIT licensed except referenced third-party works, which retain their own copyrights. Referencing a paper does not relicense it.

## Runtime dependency and environment

- Python 3.12.14 was available in the execution environment; Python is governed by the PSF License and applicable bundled notices. Python is not redistributed.
- NumPy 2.3.5 was already installed. Core NumPy license: BSD-3-Clause. Official source license: https://github.com/numpy/numpy/blob/v2.3.5/LICENSE.txt . Its installed wheel also includes separate notices for bundled numerical/runtime components; these are not relicensed as MIT. The wheel is not bundled with this repository.
- Exact installed NumPy license metadata and software versions were inspected locally. No packages were installed for this pilot. PyTorch and pytest were unavailable and not required.
- Only NumPy and the Python standard library are needed to run the code. Matplotlib, SciPy and scikit-learn were not used by the experiment.
- Run manifests contain source and output SHA-256 hashes, dependency versions, seed schedules, environment metadata, and commands. No credentials or machine-private paths are intentionally stored in public outputs.

## Limitations

The memory lookup provides a retrieved vector before neural inference. The “memory” expert is a learned classifier of that vector, not a learned memory store. The input masks expose the correct semantic decomposition by construction. Consequently these data are useful for checking instrumentation and causal-prior effects, not establishing general or biologically faithful intelligence.
